# Shared Capabilities

A collection of shared scripts and automation capabilities.

## Capabilities

### [TemplateSync](Capabilities/TemplateSync/)
Distribute VMware VM templates between vCenters without direct connectivity. Uses SMB share as intermediary, preserves instance-uuid across deployments.

### [VCF-API](Capabilities/VCF-API/)
VCF SDDC Manager API helpers for cluster commissioning — retrieve Cluster Image IDs and Host IDs by hostname for commission payloads.
